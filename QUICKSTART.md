# Quick Start 🚀

Quer começar AGORA? Siga estes 5 passos:

## 1️⃣ Instale as dependências

```bash
pip install -r requirements.txt
```

## 2️⃣ Tenha Node.js e FFmpeg instalados

Verifique se estão instalados:
```bash
node --version
ffmpeg -version
```

Se não aparecer versões, [instale aqui](README.md#requisitos-).

## 3️⃣ Para vídeos NORMAIS

```bash
python youtube_video_download.py
```

Cole a URL do vídeo e pronto! ✅

## 4️⃣ Para vídeos com RESTRIÇÃO DE IDADE

1. Abra Microsoft Edge
2. Faça login no YouTube
3. Confirme sua idade
4. Instale a extensão "Get cookies.txt LOCALLY"
5. Clique nela em YouTube.com
6. Salve como `cookies.txt` na pasta do script
7. Execute o script - pronto! ✅

## ❓ Deu erro?

Confira a seção **Troubleshooting** do [README.md](README.md#troubleshooting-)!
